# 示例 prompt

安装 Jade Grid 后，直接复制下面任意一段给 Claude 即可。不需要提到 skill 的名字，说"做网站""改版"等就会自动触发。

---

## 1. 品牌官网（展示型）

```
帮我做一个茶叶品牌的官网首页，中文为主。
品牌：山间茶事（虚构），主打高山乌龙。
目标：让第一次来的人觉得高级、可信，愿意去看产品。
访客主要在中国大陆。
```

## 2. 落地页（转化型）

```
做一个线上书法课的报名落地页。
受众：25–40 岁的城市上班族，零基础。
只要一个行动：填表预约免费试听课。
中英双语，带语言切换。
```

## 3. 表单页（任务型）

```
做一个家电维修的报修页面：选择家电类型、描述问题、上传照片、选上门时间、留联系方式。
要简单好填，手机上也好用。
```

## 4. 后台看板（系统型）

```
做一个小型连锁咖啡店的运营看板：今日营业额、各门店对比、热销单品、库存预警。
用真实感的虚构数据。
```

## 5. 改版现有页面

```
这是我现在的网站（上传 index.html），看起来很普通。
帮我改得更高端，但保留原来的内容和结构。
```

---

## 小提示

- **先看设计方案，再动工。** Claude 会先给你一份简短的设计方案（模式、风格、配色、结构），你确认后才开始写代码。想跳过就说"直接做"。
- **说清楚访客在哪里。** 访客在中国大陆时，Claude 会避开 Google 字体、地图和验证码，保证打开速度。
- **图片自己生成。** Claude 会留好图片位置，并给你每张图的英文 AI 生图提示词。
- **一个页面开一个对话**，更省 token。
