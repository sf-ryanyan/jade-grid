# Style group M — Minimal rational (read only when the chosen style is M1–M4)

## M — Minimal rational

### M1. Minimalist Editorial (document style) — system demos, SaaS, tools, B2B
- Warm monochrome: `#FFFFFF` or bone `#F7F6F3`/`#FBFBFA`, cards `#FFFFFF`/`#F9F9F8`, dividers `#EAEAEA`, ink `#111111`/`#2F3437`, muted `#787774`; colour only as washed-out pastel tags (red `#FDEBEC`/`#9F2F2D`, blue `#E1F3FE`/`#1F6C9F`, green `#EDF3EC`/`#346538`, yellow `#FBF3DB`/`#956400`).
- Type: editorial serif hero (`Newsreader`, `Instrument Serif` + `Noto Serif SC`), tracking -0.02 to -0.04em; UI `Geist`/`Switzer` + `Noto Sans SC`; mono only for keys/code/metadata. Width ~`max-w-5xl`.
- Flat bento with exactly `1px solid #EAEAEA`, radius 8–12px max; CTA solid `#111`, radius 4–6px, no shadow; pastel pill tags; box-less FAQ with bottom borders and sharp `+`/`−`; `<kbd>` keys; faux macOS window chrome around product screens; line-ink sketches with one pastel shape; faint warm light spots so sections never feel flat.
- Motion almost invisible: `translateY(12px)` + fade 600ms; cascade 80ms; card hover shadow `0 2px 8px rgba(0,0,0,.04)`.
- Banned here: pills for large containers or main buttons, gradients, neon, glass, heavy shadows, bright colour sections.

### M2. Swiss Modernism 2.0 — professional services, architecture, consultancies, B2B
- Strict 12-column grid, flush-left ragged-right, generous white, black ink + ONE primary colour (red or blue). Refined grotesk (`Geist`, `Instrument Sans`, `Archivo`) + `Noto Sans SC`; big numerals and clear typographic hierarchy; hairline rules allowed; no texture, no brutal symbols. Motion: precise slides and reveals.

### M3. Exaggerated Minimalism — luxury products, architecture, photographers, single-offer pages
- One giant word or number (15–25vw) and almost nothing else per screen; monochrome + one accent; extreme whitespace; one perfect image per section. Motion: slow scale and mask reveals.

### M4. E-Ink / Paper — reading-first: courses, documentation, fiction, newsletters
- Paper grey `#F2F0EB`, ink black, no colour except one muted link colour; serif body (`Source Serif 4`, `Newsreader` + `Noto Serif SC`); comfortable measure; no shadows; motion limited to fades. Optional dark "night reading" variant.
