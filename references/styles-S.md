# Style group S — System (read only when the chosen style is S1–S2)

## S — System

### S1. Data Dashboard (dense / executive) — admin, CRM, ordering, analytics
- Sidebar nav at ≥ 1024px, top bar with search and account; neutral palette + one brand colour + semantic colours; quiet panels (1px borders allowed), 8–32px spacing; KPI row of 4–6 (executive sub-mode: 3–4 big KPIs + trends); tables with tabular, right-aligned numbers, sticky headers, filters; charts per E7. `Geist`/`IBM Plex Sans` + `Noto Sans SC`.

### S2. Enterprise SaaS / Portal — customer portals, service centres, B2B tools
- Platform-system conventions (Fluent / Polaris-like): 8pt grid, standard components, clear forms, consistent states, generous but efficient layout, brand colour on primary actions only. Optimised for task completion; modes 3–4.
