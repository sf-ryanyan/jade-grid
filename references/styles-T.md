# Style group T — Tech future (read only when the chosen style is T1–T3)

## T — Tech future

### T1. Tactical Terminal (brutalist dark) — data, analytics, AI agents, tech dashboards
- CRT `#0A0A0A`/`#121212`, phosphor ink `#EAEAEA`, hazard red as the only accent; terminal green `#4AF626` for ONE status element. Mono dominates (`JetBrains Mono`, `IBM Plex Mono`, `Space Mono`, `VT323`) + `Noto Sans SC`; dense readouts with semantic tags (`<data>`, `<samp>`, `<kbd>`, `<output>`, `<dl>`), bracket framing, crosshairs, 90° corners; scanlines on a fixed layer; glow on key numbers only. Motion: text-scramble, blinking cursor, ticking numbers.
- Sub-mode **Sci-Fi HUD**: thin cyan/amber lines, angled corners, radar/arc gauges, for futuristic launches.

### T2. Aurora / Gradient Mesh — AI and creative SaaS, apps, fintech
- Soft slowly moving colour mesh (light or dark, colours from an analogous set), glass or solid cards above it, large clean sans (`Geist`, `Plus Jakarta Sans`, `Satoshi` + `Noto Sans SC`). Gradients allowed here; keep text on calm fills. Motion: slow drift (fixed layer), glow on focus.

### T3. AI-Native UI — AI tools, agents, AI training, assistants
- The prompt box or chat is the hero; streaming text, suggestion chips, command bar (`⌘K`), result cards with sources; neutral palette + one gradient or glow accent; `Geist` + `Geist Mono` + `Noto Sans SC`. Motion: typing/streaming, subtle shimmer while thinking.
