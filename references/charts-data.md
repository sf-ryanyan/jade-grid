# Charts and data (read when the page shows charts or data tables; always for mode 4)

## E7. Charts and data
- Pick the chart for the question (trend → line, comparison → bar, part-to-whole → stacked bar, avoid pies with > 4 slices); axis labels, legends, tooltips; never colour alone (labels, patterns); accessible palette (one hue + greys, semantic colours for status); sequential ramps built in OKLCH with even lightness steps; when chart colours can't reach 3:1 against each other (beyond ~3 colours they rarely can), give each fill a border and require 3:1 between fill and border instead; tabular right-aligned numbers; empty and loading states for charts; data that adds up.
